OttPlusV2 - Architecture Diagram

Clean Architecture Layers

Presentation Layer

ActivationActivity - Fragment container, entry point
ActivationFragment - UI: code display, progress, status, retry
ActivationViewModel - StateFlow for UI state
▼ MVVM + StateFlow

Domain Layer

ActivationUseCase - Orchestrate register + polling as Flow
ActivationUiState - Sealed class: Loading/WaitingForUser/Activated/Error
▼ Repository pattern

Data Layer

ActivationRepository - Register device, poll status, handle response
OttApiService - Retrofit interface (POST register, POST status)
OttApiClient - Retrofit + OkHttp singleton
AuthTokenStore - SharedPreferences: tokens + state
DeviceIdProvider - Persistent UUID per device
▼ HTTP/REST

Backend API (External)

POST /api/v1/devices/register → activation_code + expires_in
POST /api/v1/devices/status → status + tokens
POST /api/v1/devices/activate → called by Frontend Web
▲

Frontend Web (External)

tuweb.com/activate - User enters code, links device to account

Activation Flow

#StepComponentAction
1Register deviceTV → BackendPOST /devices/register
