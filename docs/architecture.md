## Activation Flow Sequence

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ TV App   │      │ Backend  │      │ Frontend │
│          │      │   API    │      │   Web    │
└────┬─────┘      └────┬─────┘      └────┬─────┘
     │                  │                  │
     │ 1. POST register │                  │
     │ ────────────────►│                  │
     │                  │                  │
     │ 2. activation_code                  │
     │ ◄────────────────│                  │
     │                  │                  │
     │ 3. Show code on screen              │
     │ ──────┐          │                  │
     │       │          │                  │
     │       ▼          │                  │
     │ 4. User enters code in web          │
     │ ────────────────────────────────────►│
     │                  │                  │
     │                  │ 5. POST activate │
     │                  │ ◄────────────────│
     │                  │                  │
     │ 6. Poll status   │                  │
     │ ────────────────►│                  │
     │                  │                  │
     │ 7. activated + tokens               │
     │ ◄────────────────│                  │
     │                  │                  │
     │ 8. Save & navigate to Home          │
     │                  │                  │
```
